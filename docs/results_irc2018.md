# IRC 2018 实测结果

测试日期：2026-11-02

## 实验设置

| 项目 | 设置 |
|---|---|
| 语料 | IRC 2018 第 3、5、6、8 章（PDF 共 330 页，约 96 万字符），解析出 882 个条款、163 张表格 |
| 分块 | 条款级 1623 块；固定 500 字（重叠 50）2138 块 |
| 向量模型 | BAAI/bge-m3（本地 CPU 运行） |
| 重排模型 | BAAI/bge-reranker-v2-m3，对融合后的前 20 条重排，取前 5 |
| 生成模型 | DeepSeek（deepseek-chat，temperature 0.1） |
| 评测集 | `eval/questions_irc2018.jsonl` 共 40 题：精确查询 8、模糊描述 12、查表 5、跨条款 6、追问 4、库外 5；约一半为中文提问 |
| 拒答阈值 | 向量相似度 0.6、重排分 0.01（由 `eval/calibrate.py` 校准） |

评测集写完后没有再修改术语表，属于未参与调参的留出集。

## 关键发现

1. **条款级分块是最有效的一步**：引用准确率 74% → 100%，误拒率 20% → 0%。固定长度切块会把长条文拦腰切断，模型只看到半截，要么引错出处，要么判断依据不足而拒答（A 组 7 道误拒题全部属于这种情况）。
2. **重排提升排序**：Top-1 命中率 71%（C）→ 80%（D），MRR 0.83 → 0.88。
3. **BM25 在这批题上没有带来增益**：C 组比 B 组少召回 1 题（e05“楼梯扶手的安装高度范围”），扶手高度条款 R311.7.8.1 被关键词匹配挤出前 5，模型因依据不足拒答。混合检索的收益依赖数据，需要用评测验证，不能默认有效。
4. **没有编造的条款号**：旧版校验规则把 10%～15% 的引用判为“幻觉”。逐条核对后发现，32 个被标记的条款号全部出现在检索到的原文里，是条文中的交叉引用（最常见的是例外条款里的“螺旋楼梯按 Section R311.7.10.1 执行”）。校验规则据此改为三档：出自检索条文 / 原文交叉引用 / 无依据。按新规则统计，四组幻觉引用率均为 0%。
5. **评测口径的局限**：D 组 t03“卧室楼板的设计活荷载”没有召回标准答案 Table R301.5，重排把楼板搁栅跨度表排到了前面；而跨度表表头也写明“卧室活荷载 30 psf”，模型给出的数值可能是对的，只是出处与标注不同。按条款号评测会把这类情况记为错误。

## 拒答阈值校准

| 分数 | 库内问题最低 | 库外问题最高 | 结论 |
|---|---|---|---|
| 向量相似度 | 0.612 | 0.585 | 两组能分开，阈值取 0.6，但间隔只有 0.027 |
| 重排分 | 0.023 | 0.258 | 两组重叠，不能单独用于拒答 |

重排模型对口语化的中文提问打分偏低（f04“阳台栏杆之间的缝隙最大可以留多少”只有 0.023），因此拒答以向量相似度为主，重排阈值只拦截极低分；最终由 LLM 按提示词规则兜底，5 道库外题全部拒答。

## 性能

在普通笔记本 CPU 上：bge-m3 为 1623 块建索引用时约 28 分钟，向量缓存到 `data/index/` 后再次启动只需几秒；开启重排后每题增加约 10～30 秒。
